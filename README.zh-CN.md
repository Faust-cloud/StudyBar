## 为什么做它

大多数计时器都让你先定一个 25 分钟的倒计时。但学习往往不是这样：可能先背一小时单词，再做一章数学，中间又插进二十分钟别的事。到了周末，你只想知道时间到底花在了哪里。

StudyBar 待在菜单栏里，只把一件事做好：记下每个科目学了多久。点「英语」就开始，再点「数学」，英语那一段会自动保存。用法就这么简单。

## 功能

- **一键开始**：点科目就计时，切换科目时自动保存上一段
- **今日计划**：写下要做的事，点旁边的 ▶ 就按这件事计时；没做完的自动留到明天
- **每日目标和连续打卡**：设一个每天要学的时长，达标就续上连续天数
- **番茄钟（可选）**：需要时打开，专注和休息时长都能调
- **不冤枉在纸上做题的你**：10 分钟没碰电脑，不会偷偷扣时间，等你回来再问这段算不算学习
- **能补能改**：忘记计时可以补记，时长记错可以改，也可以删
- **数据只在你的 Mac 上**：不用注册，不上传；随时把全部记录复制成表格，粘贴到 Excel 或 Numbers

## 安装

### 直接下载

1. 在 [最新版本](../../releases/latest) 里下载 `StudyBar.zip` 并解压
2. 把 `StudyBar.app` 拖进「应用程序」
3. 第一次打开时右键应用，选「打开」。应用还没有经过苹果公证，系统只会问这一次

想开机自动启动：**系统设置 → 通用 → 登录项** 里加上它。

### 从源码编译

整个应用只有一个 Swift 文件，不依赖任何第三方库。

1. 在 Xcode 里新建项目：**macOS → App**，Interface 选 **SwiftUI**
2. 删掉自动生成的 `ContentView.swift`
3. 把自动生成的 `<项目名>App.swift` 的内容整个替换成 [`StudyBarApp.swift`](StudyBarApp.swift)
4. 按 `⌘R`，菜单栏会出现一本书的图标

## 它会怎么处理

| 情况 | StudyBar 的做法 |
| --- | --- |
| 切换科目 | 保存上一段，开始新的一段 |
| 10 分钟没动键盘鼠标 | 继续计时，等你回来再问 |
| 合上电脑 | 同上 |
| 计时中退出应用 | 停在最后一次运行的时刻 |
| 连续学了 2 小时 | 提醒你起来活动一下 |
| 达到每日目标 | 发通知，连续天数加一 |

记录保存在本机的 `UserDefaults` 里，删掉应用也不会丢。

## 常见问题

**系统提示「无法打开」？**
右键应用选「打开」，或者到 **系统设置 → 隐私与安全性** 里点「仍要打开」。

**不小心删了一个科目？**
新建一个同名科目，它会带着全部历史记录回来。

**怎么备份记录？**
打开「统计与设置」，点「复制全部记录」，再粘贴到任意表格里。
