# 📖 学习计时本

一个挂在 Mac 菜单栏上的学习计时小工具：按科目计时、写每日计划、看每天学了多久。

## 功能

- **按科目计时**：点一下「英语」「数学」就开始，切换科目会自动保存上一段
- **今日计划**：写下要做的事，点 ▶ 按计划计时，没做完的自动留到第二天
- **每日目标和连续打卡**：设一个每天要学的时长，达标后连续打卡 🔥
- **番茄钟**：可选，专注和休息的时长都能调，到点有通知
- **离开电脑会问你**：10 分钟没碰电脑，回来时问这段算不算学习（在纸上做题也不会被扣时间）
- **统计**：今天各科时长、最近 7 天柱状图
- **补记录、修改、删除记录**，一键复制全部记录到 Excel / Numbers

## 运行要求

- macOS 13 及以上
- Xcode（App Store 免费下载）

## 怎么装

1. 打开 Xcode → Create New Project → macOS → App，Interface 选 SwiftUI
2. 删掉自动生成的 `ContentView.swift`
3. 把 `StudyTimerApp.swift` 的内容整个替换进项目里的 `xxxApp.swift`
4. 按 `⌘R` 运行，菜单栏会出现一本书的图标
5. 想长期使用：Product → Show Build Folder in Finder → Products → Debug，把里面的应用复制到「应用程序」

## 数据存在哪

所有记录都保存在本机（UserDefaults），不上传到任何地方。删掉应用也不会丢记录。
